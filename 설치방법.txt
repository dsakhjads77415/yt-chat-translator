YouTube 채팅 번역기 (일본어 ⇄ 한국어) v1.2

[설치]
1. 크롬 주소창에 chrome://extensions 입력
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 yt-chat-translator 폴더 선택
4. YouTube 라이브 방송 탭 새로고침
※ 크롬 오른쪽 위 퍼즐 아이콘 → "YouTube 채팅 번역기" 핀 고정하면 설정창을 바로 열 수 있습니다.

[Gemini AI 번역 쓰기 — 선택]
1. aistudio.google.com 접속 → 구글 계정 로그인 (처음이면 약관 동의)
2. 왼쪽 메뉴 Get API key → Create API key
3. 만들어진 키(AIza…) 복사
4. 번역기 설정창 → 번역 엔진 "Gemini AI" → 키 붙여넣기 → "저장 + 연결 테스트"
5. 번역 예시가 나오면 완료
- 카드 등록 없이 무료. 대신 분당·일일 사용 한도가 있고, 보낸 내용이 구글 서비스 개선에 쓰일 수 있습니다.
- 한도 초과·오류가 나면 자동으로 구글 번역으로 바꿔서 계속 번역합니다 (설정창 아래에 표시).
- Gemini는 4초에 한 번씩 묶어서 보내므로, 구글 번역보다 번역이 1~4초 늦게 뜰 수 있습니다.
- 키는 이 PC 크롬에만 저장됩니다. 다른 사람에게 공유하지 마세요.

[채팅 보기]
- 일본어 메시지가 같은 자리에 한국어로 바뀌어 보입니다. 마우스를 올리면 원문.
- 표시 방식: "번역만" / "원문 + 번역"

[내 채팅 보내기 (한국어 → 일본어)]
- 입력창에 한글로 쓰고 Enter → 일본어로 바뀜 (아직 안 보내짐, 확인용)
- 확인 후 Enter 한 번 더 → 전송
- 한글 그대로 보내기: Alt+Enter
- 설정창에서 이 기능만 끌 수 있음
- 한글 조합 중에 Enter 를 누르면 한 번 더 눌러야 번역될 수 있습니다.

[방송 음성 자막 (일본어 → 한국어) — v1.2]
1. YouTube 방송 탭에서 번역기 아이콘 클릭 → "이 탭 자막 시작"
2. 처음 한 번은 음성 인식 모델을 내려받습니다(가입 필요 없음 · "정확" 모델은 1GB 안팎이라 몇 분 걸림). 방송 화면 왼쪽 위에 진행률이 나옵니다.
3. 준비되면 방송 화면 아래쪽에 한국어 자막(+ 일본어 원문)이 뜹니다. 끌 때는 같은 버튼("자막 끄기").
- 그래픽카드로 음성 인식을 돌립니다(최신 크롬이면 따로 설정할 것 없음). 그래픽카드를 못 쓰면 "가벼움" 모델로 CPU에서 돌아가 느리고 덜 정확합니다.
- 말이 끝나고 1~3초 뒤에 자막이 뜹니다. 배경음악·게임 소리가 크면 잘못 알아듣거나 엉뚱한 말이 나올 수 있습니다.
- 자막 번역: 번역 엔진이 Gemini면 Gemini로, 아니면 구글 번역으로 합니다. 사용자 사전·내장 사전(마비노기 용어)도 적용됩니다.
- Gemini 한도: 설정창 Gemini 칸의 "내 무료 한도"에 분당·하루 요청 수를 넣어 두면, 음성 자막은 한도의 80%까지만 Gemini를 쓰고 넘으면 구글 번역으로 바꿉니다(나머지 20%는 채팅 번역 몫).
  · 기본값: 분당 15 · 하루 500 (Gemini 3.5 Flash Lite 무료 한도, 2026-10 기준)
  · 내 한도 확인: aistudio.google.com → 사용량(Usage) → "최대 사용량 추세"에서 모델 선택 → RPM(분당)·RPD(하루)의 Limit 값
  · 하루 사용량은 미국 서부 시간 자정(한국 오후 4~5시)에 0으로 돌아갑니다.
  · 음성 자막은 한 마디마다 1번 요청합니다(1분에 9번쯤). 하루 500이면 자막만으로 40분 남짓에 80%가 차고, 그 뒤로는 자막이 구글 번역으로 바뀝니다. 채팅 번역은 남은 몫으로 계속 Gemini를 씁니다.
  · 설정창 맨 아래 "Gemini 한도 사용 (분당 · 오늘)"에서 지금까지 쓴 양을 볼 수 있습니다.
- 모델 선택: 자동 / 정확(large-v3-turbo) / 보통(small) / 가벼움(base). 자막이 계속 늦게 나오면 "보통"으로 바꿔 보세요.

[사용자 사전]
- 한 줄에 하나씩 원문=번역  (예: ダンバートン=던바튼)
- 구글 번역: 번역 전에 단어를 바꿔 넣음 / Gemini: 용어집으로 전달
- 내장 사전(채팅 은어, 마비노기 모바일 직업명·지명)은 dict.js 에 있습니다.

[문제가 생기면]
- chrome://extensions 에서 이 확장의 새로고침 아이콘 → 방송 탭 새로고침
- 설정창 맨 아래 오류 메시지를 캡처해서 알려주세요.
