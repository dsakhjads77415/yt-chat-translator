# YouTube 채팅 번역기 (일본어 ⇄ 한국어)

YouTube 라이브 채팅의 일본어 메시지를 실시간으로 한국어로 번역해 **원문 자리에 표시**하고,
내가 한글로 쓴 채팅을 **일본어로 바꿔서 보내 주는** 크롬 확장 프로그램입니다.

## 기능
- 일본어 채팅을 한국어로 실시간 번역 (마우스를 올리면 원문)
- 표시 방식: 번역만 / 원문 + 번역
- 채팅 은어 사전 내장: 草·ｗｗ → ㅋㅋ, 888 → 짝짝짝, おつ → 수고하셨어요 등
- 마비노기 모바일 직업명·지명 사전 내장 (氷結術師 → 빙결술사 등)
- 사용자 사전: `원문=번역` 형식으로 직접 추가
- 번역 엔진: 구글 번역(키 필요 없음) / Gemini AI(무료 키, 은어·말투 번역이 더 자연스러움)
- 내 채팅 번역: 한글로 쓰고 Enter → 일본어로 바뀜 → 한 번 더 Enter → 전송 (Alt+Enter: 한글 그대로 전송)
- **방송 음성 자막**: 방송의 일본어 음성을 한국어 자막으로 화면에 표시 (Whisper 음성 인식을 내 PC의 그래픽카드로 돌림 · 서버·가입 필요 없음 · 처음 한 번 모델 내려받음)

## 방송 음성 자막 쓰기
1. YouTube 방송 탭에서 확장 아이콘 → **이 탭 자막 시작**
2. 처음 한 번은 음성 인식 모델(정확 모델 약 1.5GB)을 내려받습니다. 방송 화면 왼쪽 위에 진행률 표시
3. 방송 화면 아래쪽에 한국어 자막(+ 일본어 원문)이 뜹니다. 말이 끝나고 1~2초 뒤
- 그래픽카드(WebGPU)로 돌립니다. 그래픽카드가 없으면 "가벼움" 모델로 CPU에서 돌아 느리고 덜 정확합니다
- 사람 목소리만 골라 인식합니다(배경음악·효과음에서 엉뚱한 말이 나오는 것 줄임)

## 설치
1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더(manifest.json 이 들어 있는 폴더) 선택
5. YouTube 라이브 방송 탭 새로고침

크롬 오른쪽 위 퍼즐 아이콘에서 핀을 고정하면 설정창을 바로 열 수 있습니다.

## Gemini AI 번역 쓰기 (선택)
1. [aistudio.google.com](https://aistudio.google.com) 접속 → 구글 계정 로그인
2. **Get API key** → **Create API key** → 키(AIza…) 복사
3. 확장 설정창 → 번역 엔진 **Gemini AI** → 키 붙여넣기 → **저장 + 연결 테스트**

카드 등록 없이 무료입니다. 무료 키는 사용 한도가 있고, 보낸 내용이 구글 서비스 개선에 쓰일 수 있습니다.
무료 한도는 AI Studio → 사용량(Usage)에서 모델별 RPM(분당)·RPD(하루) 값을 확인해 설정창 **내 무료 한도**에 넣으세요
(기본값 분당 15 · 하루 500 = Gemini 3.5 Flash Lite 무료 한도, 2026-10 기준).
방송 음성 자막은 이 한도의 80%까지만 Gemini를 쓰고, 넘으면 구글 번역으로 바뀝니다(남은 몫은 채팅 번역용).
한도 초과·오류 시에는 자동으로 구글 번역으로 바뀝니다. 키는 내 PC의 크롬에만 저장됩니다.

## 사용한 오픈소스
- [Transformers.js](https://github.com/huggingface/transformers.js) 4.3.1 (Apache-2.0), [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) (MIT) — `lib/` 폴더
- 음성 인식 모델: OpenAI Whisper (MIT) — 처음 쓸 때 Hugging Face 에서 내려받음

## 주의
- 기본 엔진은 비공식 구글 번역 주소를 사용합니다. 요청이 많으면 잠시 막힐 수 있고, 구글이 막으면 작동이 멈출 수 있습니다.
- YouTube 화면 구조가 바뀌면 작동하지 않을 수 있습니다.
- 개인이 만든 비공식 도구입니다. YouTube·Google·넥슨과 관계없습니다.
