Gemini API 키
모델
Gemini가 한도 초과·오류일 때는 자동으로 구글 번역을 씁니다. 키는 이 PC의 크롬에만 저장됩니다.
내 무료 한도 — AI Studio → 사용량(Usage)·한도(Rate limit)에서 지금 고른 모델 값을 확인해 넣기
음성 자막은 이 한도의 80%까지만 Gemini를 쓰고, 넘으면 구글 번역으로 바꿉니다(나머지 20%는 채팅 번역 몫). 하루 한도는 미국 서부 시간 자정(한국 오후 4~5시)에 초기화됩니다.
API 키 발급 방법 (무료, 카드 불필요)
  1. aistudio.google.com 접속 → 구글 계정 로그인
  2. 처음이면 약관 동의
  3. 왼쪽 메뉴 Get API key → Create API key
  4. 만들어진 키(AIza…)를 복사해 위 칸에 붙여넣기
  5. 저장 + 연결 테스트 클릭 → 번역 예시가 나오면 완료
무료 키는 분당·일일 사용 한도가 있고, 보낸 내용이 구글 서비스 개선에 쓰일 수 있습니다. 키는 다른 사람에게 공유하지 마세요.
